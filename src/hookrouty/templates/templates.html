New template

Field kinds: text, url, secret, select, json. Each field has key, label and kind; choices use options. Use {% raw %}{{inputs.key}}{% endraw %} in mapping values. URL inputs can supply the whole base URL; other path inputs are encoded. Secret inputs cannot have defaults, and their mapped headers/query/body are encrypted automatically. Templates are data, never executable code.

Editing or deleting a template does not change hooks already created from it. Use “Copy” on an existing definition as a starting point.
